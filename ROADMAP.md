# Roadmap / 未来方向

- **v0.6.1: fix unstable tests first**, with reproducible world/weather/time fixtures and real input diagnostics; preserve the original assertions and thresholds. / **v0.6.1第一件事：修复不稳定测试**，固定可复现的世界、天气和时间夹具，补足真实输入诊断，保留原断言与门槛。
- Improve reliability and clarity from real player reports. / 依据试玩继续修可靠性与表达。
- Test more operating systems and hardware with contributors. / 与贡献者扩大系统与硬件实测。
- Complete provenance and attribution records, especially fan designs. / 补齐来源与同人作者署名。
- Refine genuinely drawn character actions and consistent pixel art. / 精修真实人物动作与像素画风。
- Evaluate long-session memory, optional AI and Lifeblood using explicit budgets and real evidence. / 以明确预算和真实证据验证长期记忆与智能。
- Extend island life gradually while preserving offline play, real materials and player choice. / 在保留本地可玩、物资守恒与玩家选择的基础上逐步扩充海岛生活。

These are directions, not delivery dates. / 以上是方向，不是交付日期。
