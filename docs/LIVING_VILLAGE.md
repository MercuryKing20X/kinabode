# 紧凑田地和居民生活 · 0.7.1

本轮用户要求：所有农田间距一致、种满植物、把房子建起来、增加散步的居民；随后明确要求避免重复外形，指定蓝发蓝裙、橙发橙裙、黑发黑衣红围巾三套角色。

## 地图与农田

四片田统一为4列×3行，共48块；中心间距2.8×2.4格，土垄2.6×2.2格，窄田埂约0.2格。取消原来独立的旧菜园绘制，所有田地、围栏、入口、点击范围与碰撞由同一套 FarmSystem 数据驱动。蔬菜每块田显示三簇，树冠和果灌木按相同地块尺度绘制，避免一大块草地上孤零零放一株植物。

farm layout version2兼容version1存档，移动同ID作物与箱子至紧凑布局，保留生长时间、已用种子和箱内物品；增加18个空田块，不补发旧箱子种子。v1原定义保留在farms-v1.json用于严格校验和迁移，不从玩家存档拿任意地图参数当权威。

新增manage_farm mode=plant：只填满并浇水，完成后停止，不会在成熟时把整片田又收成空地。crop_id=mixed仅对该模式有效，按本农庄适种作物轮换。仍需要实际取种、携带、播种和浇水；没有注入作物、库存或虚构建屋投入。

## 日常走动

VillageLife使用数据化路点与短暂停留，米拉在家园/菜园附近散步，诺拉往返果园入口与村路。采用World唯一寻路/移动，不创建模型连接、不采集物资、不占用模型居民名额、不会控制玩家。

Codex闲时更频繁散步，短暂停留间隔3–5秒，并穿插眨眼、张望和伸展。活动围绕结束工作时的位置展开，避免越走越远。农庄等待生长时允许本地散步；有工作、模型对话或待答问题时任务优先。手动停止仍保留安静期，不用自动走路反复覆盖用户指令。

导航缓存静态海岸、池塘、农田围栏与箱子，仅在动态树木/房屋附近更新格子，避免砍倒每棵树后重算整岛的复杂几何。人物始终按原正常/负重速度走路，NPC也使用相同合法路径。

## 实际场景准备

建屋通过运行中的Godot bridge调用build_house/resume_project，木材来自实际伐木和搬运，不直接改存档阶段。种满通过明确分配管理权限后的plant订单执行，不自动收获；作物继续遵守各自真实生长时间。QA截图在临时目录内通过实际规则播种/建屋，再推进模拟时钟以检查成熟外观，不把这些截图当成玩家存档已成熟的证据。
