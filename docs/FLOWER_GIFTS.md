# 路边摘花赠礼 · 0.10.2

居民待机时偶尔走近路边花丛，低头摘花，拿到玩家身旁并递出；花只是临时画面道具，没有物品ID、背包数量、掉落、交易或建造用途。花丛不被采空，农田里的雏菊不是此行为的资源来源。

逻辑在 `flower_gifts.gd`，作为 LocalCompanion 的 `flower_gift` 状态接入每位非玩家居民。沿既有道路生成固定装饰花丛，排除路心、农田和不可行走位置；渲染与寻路使用同一组位置。World 仍独占移动，动作不另起模型或工具任务。

默认配置在 `content/companions/local-life.json`：首次至少75秒、每位居民240～420秒冷却、全村间隔至少65秒，一次只安排一人送花。是低频加权待机选择，不保证倒计时结束立刻发生。只在主岛、空手、玩家16格以内尝试；附近12格以内找花。摘花2.2秒、递花3.6秒，靠近后最多2次调整路线、全程最多35秒。玩家走远或进屋自然取消。

工作、建造计划、农事、聊天、待答问题、集合和停止仍有优先权。关闭日常活动会清除动作和道具，显式停止继续遵守120秒安静期；取消不改物资。读档不恢复待机流程或虚构一朵手持花。关闭碎碎念仍可无声送花；赠花短句遵守已有发言冷却和全村气泡限频。

画面沿用已有拾取/站立姿态，增加轻微俯身、手中小花、递出与淡出表现。`flower_pick_<方向>` / `flower_offer_<方向>` 是可编辑专用帧的扩展名；当前没有新生成整套手绘帧，缺帧时回退到角色自己的现有帧。花朵来自既有原创 `assets/island/flowers.png`，无新生图调用。
