# 有栖0.6 · 一起把房子盖好

2026-10-24。目标是一次表达完整建屋意图，由伙伴按真实进度持续参与，玩家可以随时加入。

## 玩家入口

点宅地，选已保存图纸，再点“和codex一起建好”；或在对话中说“我们把这座房子盖好吧”。若需要你决定房子或外观，AI在游戏里问清楚。图纸一旦成为计划目标就锁定，未开工时需取消计划才能更换；已开工房屋继续原图纸。

计划卡显示房屋、已完成阶段、投入材料与当前步骤。暂停停止整个计划，继续重新检查当前世界；取消结束计划但保留全部材料和建筑投入。重启保留计划并暂停，不自动继续工作。“商量一下”主动发送真实AI请求，等待问题答案不是授权。完工后提供“进去看看”，可收起完工卡。

人类仍独立操作。你可采木入箱、拿木材到宅地用“送来手中的木材”帮助伙伴，或在伙伴未占用施工时自己完成一个阶段。计划会读取实际进度，跳过你完成的阶段。交料并发不重复扣除；超出当前阶段需求的手持材料保留。

## 工作规则

每位居民一个当前计划，同一宅地一个未结束计划。计划只规定目标，不包占树木/箱子/宅地；现有子任务预约当前目标，施工仍互斥。完整计划最多五阶段，可接着原有建筑进度完成。

1. 核对房屋是否已完成、当前阶段、已交材料、手持和可达箱子库存。
2. 如果在室内，先经门口走出；先收好蘑菇，抱着家具时要求放下。
3. 有实际木材就搬到工地，凑齐当前阶段费用才施工。没有足够材料时，每次采一棵并真实搬运，随后重新核算。
4. 可达地面遗留木材先回收，伐木范围沿用第一次选择的资源区。普通劳动由引擎执行，不逐树调用模型。
5. 玩家补足当前阶段时，停止继续砍尚未倒下的树，保留树上已经实际发生的损伤；已掉落/携带/入箱的木材不删除。伙伴已在施工时等待该阶段结果。
6. 箱满、道路不通、地基里有人或选定资源区无法供应时进入blocked，显示真实原因，不无限重试。解决问题后用户点继续，或点商量重新决策。
7. 实际第五阶段完成才记录completed、一次完工记忆和进入房屋入口。完工邀请是明确标记“日常”的引擎短句，不假扮模型推理。

## 状态与接口

`construction_projects.gd`维护plans、完成memories；WorldWork仍负责劳动和材料转移，所有入口都走同一验证。父计划稳定id，子任务各自有job_id并携project_id。状态active/paused/blocked/completed/cancelled，步骤preparing/gathering/delivering/building/waiting_partner/leaving/storing。

| intent | 参数 | 行为 |
|---|---|---|
| build_house | target_id | 开始完成指定房屋剩余阶段的计划 |
| pause_project | project_id | 暂停自身计划并释放子任务占用 |
| resume_project | project_id | 按当前世界继续自身暂停/阻塞计划 |
| cancel_project | project_id | 结束计划，保留资源与投入 |
| deliver_wood | target_id | 将手中木材实际送到宅地，可协助其他施工者 |
| stop | 无 | 有活跃计划时暂停整份计划，否则原动作停止 |

observe包含self.project、projects和house_memories。计划摘要含当前construction、贡献ledger，不带整份像素图。桥接层区分已完成的图纸选择与接单的持续任务：允许先选已保存图纸再下完整建屋任务，不允许重复安排采树/阶段。暂停与取消可在当前有任务时执行。提问暂停计划；用户回答后模型仍需根据明确授权提交继续命令。

## 守恒与记忆

每次实际交料增加site.contributions[actor_id].wood；实际完成阶段增加stages。只记录此次功能上线后可观察的贡献，旧存档历史不倒推、不编造。完工记忆复制已发生的账目；只有codex劳动时不声称人类也贡献了材料或施工。

schema5新增计划和完成记忆，兼容schema2/3/4。加载验证居民所有权、稳定ID、宅地、锁定图纸、状态/阶段、贡献上限和记忆；取消计划后允许未开工图纸已经变更。重载清空当前工作与占用，active转paused，保留手持/掉落/投入。无效数据保留恢复副本。

## 验证与当前边界

自动化在临时HABITAT_DATA_DIR内真实采集与施工，覆盖空库存一条指令完成、蓝屋与在建进度、两人交料/施工、补料后停止多采、暂停/取消/重载、堵路/储存不足、身份隔离、完工记忆幂等、旧存档与损坏恢复、真实界面按钮及问题等待。图像证据project_paused.png/project_complete.png来自Godot viewport，素材和人物未换。

当前实现只针对建屋，尚非通用多目标规划器；家具布局与农田规划不自动追加。阻塞后的“商量一下”由用户发起，不自动唤醒模型或调用其他AI。当前完工小屋仍是一层通用起居室。真实模型协议已更新，本轮默认使用模拟模型做契约验证，不承诺每种自然语言说法都一定选择正确工具。
