## 玩家如何使用

打开「对话」，先选一位居民。控制方式可以选择「Codex 接入」或「本地互动」；下方「日常活动」和「碎碎念」只影响当前选中的居民，设置分别保存。旁边显示这位居民目前正在散步、看田地、玩设施或执行安排。

四位居民默认都能自由活动，小白偏爱秋千和陪伴，小蓝偏爱舞台，小橙偏爱看田地和休息，阿黑偏爱观察与安静停留。这些是可修改的选择权重，不是强制日程。居民会结合附近设施、空位、距离、近期活动及冷却选择，避免连续重复同一活动。设施必须已经由正常规则建好。

与小白聊天或等待她回答时，其他居民照常活动。工作、待答问题、集合优先；点击「停止伙伴」后，这位居民保持约120秒安静。关闭日常活动只取消她自己的闲逛或自主游玩，不取消你明确安排的施工、砍树或其他任务。玩家角色完全独立。

控制方式切换会暂停这位居民原有任务，保留其身份、外形、名字、物品、建设投入、农场归属和已有记录。小橙可以接上Codex聊天，同时仍是同一位小橙；接入不会自动赋予她砍树和管理农场的能力。当前NPC默认只有社交能力，创作者可在居民资料里明确添加工作能力。

接入使用本机已登录的Codex，每个居民独立绑定会话。选择「Codex 接入」仅准备连接，第一次发消息才启动模型；本地生活、寻路、坐秋千、跳舞和日常短句不会调用模型。没有自动轮询或任务结束后的推理唤醒。

## 结构

- `ResidentCatalog`：稳定ID、名字、外形、默认控制来源、能力和生活偏好。
- `ResidentDirector`：每个非玩家居民一个同样的本地状态机，汇总生活状态、目的地占位、日常气泡限频。
- `LocalCompanion`：现在为按resident_id实例化的通用日常实现，不再只写死小白。world.local_companion仅保留为旧测试和历史设置迁移的别名。
- `VillageLife`：只保留旧居民目录与存档兼容入口；不再有第二套巡游执行循环。
- `World` / `Work`：唯一移动、任务和占座规则。日常请求同样经过合法动作验证，渲染层不修改模拟位置。
- `CompanionLink`：只负责该身份的模型通道，与外形和工作能力分离。

行为包含散步、张望、轻微舒展、靠近玩家、在空座休息、到田边观察，以及使用完成的秋千/凉亭/舞台。看田地不采摘、播种或改变物资；自主生活不施工、不主动进食、不主动消耗资源。等待作物成熟时可以短距离散步和休息，但不启动会阻塞农事的设施工作。

活动选择每几秒才发生一次，时间错开；移动仍用固定世界速度。自主设施任务标记source=local_rules，记录精确job_id。真正命令到达时只取消该本地任务和该本地路径，释放自己的座位；不会误删另一位居民或新接下的用户任务。设施用完回到闲时选择，满位/不可达后有冷却，不持续刷请求。

## 数据接口

`godot/content/residents.json`中的可选字段：

```json
{
  "controller": "local",
  "capabilities": ["social"],
  "preferences": {
    "weights": {"wander": 3, "garden": 4, "facility": 3},
    "facilities": {"swing": 1, "sit": 5, "dance": 2},
    "wander_radius": 8,
    "facility_radius": 38
  }
}
```

controller为human/model/local，human仅允许玩家身份。capabilities支持social/work；切换模型来源不改变能力。偏好权重0–10；活动范围2–48格，实际小步散步限制在附近。缺失字段兼容旧居民定义，名字与已有ID不变。

每位居民的世界快照增加control：controller、effective、capabilities、local_life。有效状态分辨assembly/conversation/task/command/local_rules/idle。普通快照不暴露像素数组或凭据，也不把每帧倒计时放入角色快照导致无revision变化的数据漂移。

主机切换控制来源时，取消对应模型代次并等待既有cancelId确认流程；撤销该居民外部API token，其他居民token不变。切回模型会分配新token；旧请求不能重新取得控制。来源为本地时，主控制器也拒绝迟到的模型动作和对白。模型没有修改自己/别人控制来源的工具。

## 保存和边界

控制来源保存为演员controller字段，沿用兼容的schema7可选字段。旧存档按目录默认值加载。每位居民的日常开关存于local-life.cfg的resident:<ID>节；旧life节只迁移小白活动开关，碎碎念静音沿用用户偏好。重启不恢复旧的临时游玩、集合、路径或座位预约；游戏启动后由已启用的本地调度重新选择生活活动。工作计划仍按原规则保持暂停。

这轮没有新接入其他模型服务；「Codex 接入」统一使用本机Codex。日常偏好在JSON中可编辑，尚未新增可视化偏好编辑器。动作沿用已有像素帧与原有轻量动态，不把本地短句称为模型想法。
