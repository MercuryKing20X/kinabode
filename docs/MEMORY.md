# 2026-11-08 伙伴记忆本


数据目录下 `memories/<entry-id>.entry.json` 每条一个分卷，单条最多 64KiB；`deleted.json` 是删除标记，`signing.key` 是本机生成的回忆数据签名私钥。这不是模型登录凭据。写入先临时文件再改名，已有有效 JSON 留 `.bak`；读入损坏 JSON 时尝试副本，非法条目不执行任何世界动作。新游戏只归档世界文件，不清记忆目录。自动备份纳入这些文件，仍受原备份大小与保留策略限制。

条目字段：`id/resident_id/world_id/event_id/layer/text/params/day/at/source/participants/photo_id`。ID 为 resident、world、event、layer 的 SHA256；居民使用稳定 ID，外观、名字、模型提供方不参与身份计算。五层为 facts、about_you、feelings、letters、daily；后三层预留，当前不调用模型编写。照片 ID 预留为空。游戏事实来自原 canonical 提交点；迁移保留仍存在的原事实与 provenance，未知旧游戏日记为 0，不能把迁移当天算作历史发生日。没有补发物资或好感。

本地玩家明确的“我喜欢…”/“I like …”同时进入关于你，保留原话与出处。最近 2000 条玩家原话留在事实层，更早条目按世界、游戏日、频道并入每日摘要分卷（每卷32句，每句最多80字），保留来源ID；源原话文件退休，事实事件不受此限制。此处不是 AI 推断的偏好。

初始界面“记忆”和游戏内手册的记忆入口复用 `memory_book_panel.gd`：伙伴选择、我们的日子、关于你、信箱、回忆册、每页 10 条及删除/导出/导入。回忆册页目前是各层记录的合并列表，信和照片没有虚构内容。

删除只作用于记忆本及其派生来源，不回滚已发生的世界事件或关系结果。删除原话会撤去依赖它的关于你条目；删除关于你也移除对应原话来源。原 SharedMemories 的模型查询、本地提醒会过滤此居民的忘记标记。游戏内删除同时清理本轮聊天上下文中的对应原话、取消此居民未完成的模型回复；下次内置意图会话在 forget_revision 改变后另开会话，避免历史提示词重新带入已删事实。外部提供方已持有的上游会话无法由游戏抹除。

原话和派生偏好保留 channel；群聊卡片排除私聊原话、私聊偏好和私聊摘要，来源不明也保守排除。

AI 卡片函数 `MemoryBooks.card(resident,query,channel)` 返回 daily、about_you、facts，每项只有 ID 和可读文本。选取最近三个有摘要的世界/游戏日、最多十条关于你及最多五条相关事实；无命中时取最近事实。`content/memory-books.json` 的 card_chars 默认 2200，可配置 256～4000。当前中文相关性匹配仍有缺口；最近三个有摘要日不等同当前世界最近连续三天。
