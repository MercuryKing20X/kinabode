# 基本动作与岛上纸条

原生回包可用 `intention: {reason, steps}`。每位伙伴同时最多一张计划，包含一到六个动作，理由最多 160 字。执行前验证结构；实际运行时再次检查路线、当前任务、停止、饥饿、所有权和权限。失败结束计划，原因随下一次意图卡发送。工作步骤用原任务 ID 等完成回执。既有活动仍可从原活动卡进入；看海、拜访和项目到场共用基本路线入口。

| 动作 | 参数和执行条件 |
| --- | --- |
| go_to | target：本岛的人、物件、收件纸条或已列出的地点。经 World。 |
| follow | target、seconds：同区域的另一个人，1–30 秒，仅移动说话者。 |
| wait | seconds：1–30 秒。 |
| say | target、text：同区域近处的人，使用原共享发言出口。 |
| gesture | kind：wave 或 stretch，使用已有反应任务。 |
| pick_up | item：允许的仓库玫瑰，或附近未认领木材的真实落物 ID。仓库食物不允许。 |
| put_down | item：本人持有的玫瑰或准确的待安置鱼 ID；只在门口提交。 |
| give | target、item：附近收件人和本人真实持物，复用背包和收件校验，不加关系分。 |
| use | target：自己的纸条、已建营火、允许的长椅或已建住房；鱼竿仍走原获准钓鱼流程。 |
| place | item：持有的玫瑰，邻近有效空地，使用原可摆花地形与上限。 |
| write_note | target、place、text、en：准确收件人、已开放纸条位置和双语短句，各 120 字。 |
| build | target：真实未完成工地，只使用工地已有模板。显示岛主同意卡，提交时复验计划、步骤与工地。 |

纸条最多同时 12 张，单人至少间隔 180 游戏秒，经过 3 个游戏日收走。门口礼物不随纸条到期；只有正确的主角按钮可以拾取，入原物品仓库或鱼类库存。单一鱼实例在门口时不可放生或移入渔场；读档校验鱼与礼物逐条对应。纸条、礼物、首次事件位和频率保存在可选 schema7 字段，旧档缺字段时为空，不恢复路线与计划。
