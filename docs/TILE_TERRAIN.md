# v3瓦片地形基础（样板专用）


TileTerrainData只持有六类材质、整格位置、半层高度和石阶，来自island-v3-sample.json。32px格、每半层16px；不持有居民、任务、资源、时钟或路线。外界越界/水面/崖脚不通行，邻接跨半层只能走石阶；不允许对角跳跃或跨多个半层。load_data/set_cell先验真再提交、失败保持原数据；cell返回副本，真实变更递增revision。

TileTerrainRenderer只观察数据：N/E/S/W邻接决定材质过渡，边缘以确定性像素轮廓拼接；六种地面以共享48色绘制，石阶/崖面由同一高度数据派生。一次静态ImageTexture地面缓存，只有terrain.revision或显式重新configure的美术规范变化才重建；每帧不生成多边形偏移，不消耗游戏RNG。夜间只合成环境色，不重新生成地面。

目前仅独立样板使用，不把它注册进WorldCatalog、不更换IslandView，不提供新地图导入/热加载/行走API。真实World仍是唯一移动权威；样板没有移动控制。数据的walkable/can_step供后续地图接线使用，未来全岛接入时仍需World寻路/碰撞缓存和旧档迁移专项，本轮不提前切换。

材质/高度是语义数据，纹理与明暗是表现。道具/房屋遮挡不能偷偷改数据可走性；正式场景还需真实设施足迹校验。顶部半层留白裁剪等情况需在全岛相机边界验收，本轮样板房屋不在顶部边界。
