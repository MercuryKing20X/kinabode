## 分类

- 人物：作品只列人物；当前为你、codex，已有额外居民作品也会按kind自动归类。依次选择外观/行走/劳动/生活、动作、方向、具体帧。砍树左侧只显示抬斧/击中/收斧。通用生活动作不显示无意义的方向选项；未知帧放在生活→自定义动作，避免作者扩展的帧丢失入口。
- 建筑：只列建筑模板，默认显示stage_4完成外观，施工帧单独选择。结构与用料为可折叠区域，含结构尺寸/费用/把已保存模板用于所选宅地。编辑器明确说明已开工房子保留原图纸。
- 设施：只列设施作品，按未使用/生火/烤制/余烬等真实状态编辑。

同一Canvas/CharacterLibrary仍处理任意像素和图层，没有把人物限制成预设部件，没有分裂三个存档格式。workshop_catalog.gd只描述帧导航和预览序列，作品源格式与AI读写接口保持兼容。

## 开关与草稿

主界面“像素工坊”是toggle；右上角收起和Esc同样关闭，按钮始终露在工坊外。弹出的颜色选择器/选项菜单会先处理Esc。收起释放绘画拖动和键盘焦点，不继续画线。

本次运行中每份作品分别缓存：像素/图层、基础版本、是否未应用、当前帧和图层、动作/方向选择、撤销重做栈、画笔颜色/模式、结构面板折叠、滚动位置和预览状态。切换分类时回到该类最后编辑的作品；关闭再开回到最后作品。缓存存在内存，不跨游戏重启，界面会提示保存。

“保存并应用”才写入CharacterLibrary和作品文件。关闭或切换不会自动发布。其他AI修改作品后，干净缓存重新打开时跟进新版本；有未应用修改则保留基础版本，保存遇冲突被拒绝，草稿不丢。不覆盖对方的更新。

显式“载入已保存版本”或“撤回上次应用”若将丢弃当前草稿才弹确认；普通关闭没有确认打断。已应用的撤回仍是既有本次运行历史能力。场景/身份/建材/地图数据不因分类或收起而改变。
