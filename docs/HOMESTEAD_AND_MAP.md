# 家园、地图与田地 · 0.4

2026-10-23。用户指定这轮优先“外观、院子与建造过程”，并补充：两个人物保留，其他地图不需要保留，可以全面更新，以合理合适为准。人物身份与可编辑外观不重做。本轮沿用好用的家园位置，同时重做地面/道路/院落，向东南扩展；不因为旧边界限制规划。世界升级仍实现为新增内容合并，没有必要清掉已建成果。

## 空间规划

初晴岛边界从96×80扩为160×128逻辑格。实际陆地多边形面积从约4668扩到12325平方格，约2.64倍，非只放大镜头。仍在现有8192×8192海域中，不与另外两岛占地重叠。

14个固定用途分区：原家园宅地、菜园、资源林、果园预留地、家园南庭、烧烤草地；新增北部松林、东部阔叶林、林间仓储、南部宅地、东部果园预留地、林间池塘、南部沙岸、北坡花径。通路连接家园—菜园—南庭—沙岸与旧林—林间木箱—两片新林地。7个主要地标可通过实际寻路到达；木箱地标指向箱前，避免把箱子本体当成站立位置。

树木从24增加到76（新增52），全部可用同样chop规则砍伐；新木箱初始为空，新增南庭宅地也使用同一五阶段建造。树木避开新通路。池塘是不规则水面，碰撞与画面使用同一形状，需绕行；目前没有钓鱼。果园与沙岸仍是预留用途，没有假装已完成果树种植/码头/航海。

顶部“地图”首先打开本岛规划图；点击岛内位置把镜头移过去，居民不会瞬移。缩小仍可看群岛，其他岛留给后续航行。地图规划符号与实际游戏画面区分，不把规划图当作最终美术。

## 菜园整理

原来地表多边形、弯曲田垄、外围围栏与道路各用硬编码坐标，造成边沿不齐和入口衔接不统一。现在布局放入core.json的home.layout；HomeLayout负责共同几何。

十二个实际farm_plot ID对应4列×3行菜畦，地表和田埂平直，横纵通路连到东侧入口；没有改变为全地图种植。围栏按同一坐标参与碰撞和Y排序。道路改为像素尺度偏移并平滑转角，避免小尺度偏移造成的尖角与断续。作物种植系统本轮仍未实现。

## 房屋与院落

点宅地或房屋打开小型建造面板：显示外观预览、当前阶段、总投入/本阶段缺口/箱内木材，可以自己施工或向真实Codex发请求。家园与南庭各自选图纸，工坊“用于宅地”使用当前选中的宅地，不再总写入home.house.01。

三份可编辑模板：林间小屋、带廊大屋、海蓝小屋。蓝色模板在原作品上重配屋顶与上部木饰颜色，不是新第三方资产；与同结构红屋顶费用相同（60木材），大屋130。原先已开工的图纸与费用保持锁定，编辑模板用于后续房屋。新模板仍是整个像素图层可编辑，不做只改按钮颜色的渲染旁路。

空地显示桩位和边界，选中图纸可见地基预览；施工显示当前阶段、脚手架和下一阶段渐显。可见材料堆与实际delivered关联。五阶段同脚点与尺寸，房屋按前沿Y坐标遮挡。院子包括铺地、门前石步道、后期花丛灌木、完成后的短围栏与入口；围栏有实际碰撞。

如果有居民站在地基范围里，完成地基前暂停并保留实际送达木材，人员离开后可继续，避免把人封在建筑碰撞里。任务接受与完成仍分开，取材/分捆/运输/存档守恒不变。没有本轮之外的室内、家具系统或拆除功能声明。
