# 本地生活伙伴 · 0.3.3

2026-10-23。用户授权“增加些离线智能，用代码堆，加上些自言自语，或者对主人的对话”。这里的离线是游戏打开时无需网络或模型推理；关闭Godot后不运行后台任务。

## 当前行为

只有codex启用，玩家与其他外接居民不接管。LocalCompanion以小状态机选择看看周围、轻微舒展、附近散步、靠近玩家、看向玩家、坐凳子歇脚。每轮结束后间隔8–16秒，尽量不连续重复同种行为；只在附近寻找可到达的位置，不跨岛、不瞬移、不自动砍树/建造/烹饪或取用库存。正常150px/s和负重125px/s保持上一版设置。

本地活动默认开启，World单独实例默认关闭，正式main按玩家设置开启。随机步行每次2–3格，靠近玩家时保留至少1.8格；在玩家12格范围内闲逛时不主动越出这个范围。只在营地附近且冷态/余烬时选空座休息，使用相同的座位占用表，结束/停止释放。空手休息不创建食物或共同用餐记忆。

## 本地短句

台词与间隔在godot/content/companions/local-life.json，可扩展。根据附近玩家、砍树声、树木、施工进度、营地烹饪/待翻面/成品状态选择已有短句。初次约12秒后可说话，之后32–55秒冷却；重复台词会回避最近使用的内容，最多保留16条临时事件。不把世界全部信息当作角色已经看见。

气泡明确标记“日常 ·”，输入框里的普通消息仍然发给真实Codex。自动台词不刷进对话记录；点“招呼她”产生的本地回应在记录中也标“日常”。本地台词不是模型想法、不是断线时伪造的回答，也不会替玩家回答模型问题。

“对话”面板提供日常活动、碎碎念两个独立开关，以及招呼她、过来陪我两个本地操作。开关存于同一数据目录的local-life.cfg，和世界进度分开。关闭碎碎念禁止自动台词，明确点招呼仍可回应；关闭日常活动停止本地行为与本地按钮响应。

## 控制优先级

1. 真正的模型正在连接/思考/执行工具/等待回答/取消，或玩家正输入、编辑作品时，暂停本地行为并清除本地气泡。
2. 真实工作、明确移动、手中携带物优先，闲逛不接管或中断这些任务。
3. 合法的Codex动作在规则入口夺回本地路线和座位，随后走相同的游戏验证。显式stop让本地活动至少安静120秒；暂停状态切换不能缩短这段时间。
4. 本地气泡不覆盖仍显示着的真实模型气泡。排队日常事件在暂停时丢弃，不晚到插话。

内置模型的is_busy用于自动暂停。外部AI的思考状态目前无法知道，但其实际命令仍会夺回控制，observe中的self.local_life会标记本地行为/暂停/开关状态。没有新增后台推理、自动模型唤醒或五个模型会话。

## 实现与验证

local_companion.gd持有弱世界引用，不导入任何模型或网络模块。移动调用World.command的move，再由WorldState统一前进；LocalCompanion只在已获本地控制时设置闲置姿态和座位占用。ActorMotion仍只表现、不写角色位置。存档只保存现有进度和位置，临时活动/路线/台词不恢复。

新增空手休息帧rest_empty来自既有standing_up作品帧，可在同一个像素工坊编辑，每个人57帧。本轮没有生图请求；舒展是小幅形变，尚未加入手绘完整伸懒腰或发梢裙摆动作。
