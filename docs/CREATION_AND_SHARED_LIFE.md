# 统一像素创作与共同生活

日期：2026-10-23。状态：新增需求与实现建议；未实现建筑创作和烧烤玩法。

## 用户确定的方向

- 当前画风暂时保持，不重新更换整套风格。局部改进围栏和田地的自然程度；用户已纠正“天地”为“田地”。
- 像素模块不仅制作人物，也制作房屋和烧烤相关外形、动作。玩家和自己的AI都能参与编辑作品。
- 房屋外形可自主编创，作品能够转成游戏里的建筑模板；不同设计需要不同数量的木材。
- 核心是和AI一起消磨时间、创作、劳动和生活。新增野外烧烤作为共同活动，不能只做材料兑换按钮或被动等待进度条。

## 围栏与田地

围栏需要连续的横向段、纵向段、转角与门口，统一透视、柱距和接地位置。先解决断开的栏片与突兀的竖向段，不靠随机散摆制造“自然”。门口与道路连接；若作为实体障碍，碰撞和可通过的门必须与画面一致。

菜地仍位于预规划耕种区。视觉上形成整片有边界的土壤，内部有连贯田垄和可走的畦间路；柔化草土边缘，增加少量不重复的土色和边角变化。可种植单元保留稳定ID，但不把逻辑格子画成孤立的矩形贴片。装饰草花避开耕种单元与操作通道。

## 像素工坊的扩展建议

保留共同的画布、调色板、自由图层、逐帧编辑、撤销、版本和预览；按作品用途补充元数据。当前 CharacterLibrary 强制四方向三帧、绑定人物ID，不能直接拿它保存房屋。应抽出公共作品能力，再分别提供人物、建筑、设施的校验器，而非让每种作品强行带十二个人物帧。

作品可以从空白或可修改模板开始。默认房屋、烧烤设施也走同一流程，不能把它们留成不可编辑的专用PNG。原始像素数据与编译结果分开保存。

“编译”建议指：将可编辑作品及用途数据检查后，生成游戏可读取的图片/动画和对象定义；普通创作不要求玩家编程。用户若用开发AI写扩展脚本，仍属于另一个明确授权的开发入口，作品图片不自动获得代码执行权限。

流程：编辑作品 → 设置用途、尺寸与交互点 → 预览外观/遮挡/占地/动画 → 计算材料 → 保存模板版本 → 在允许的区域开工。

## 自由建筑与木材需求

房屋模板至少需要外观作品引用、实际占地、门口与进入点、碰撞、遮挡排序、施工阶段和结构数据。绘制外形不自动生成可信的室内或正确的施工阶段；缺少信息时由编辑器提示补充、由玩家或AI制作并预览。

建议按游戏里的结构计算材料：地板面积、墙体用量、层数、屋顶结构、门廊等分别贡献材料，再汇总到各施工阶段。外形创作依旧自由，这些数据用于确定实际体量和施工成本，不限制固定几套房型。尺寸和结构须与实际占地、可用空间相符。

不按图片分辨率、涂色像素数、颜色深浅收取木材，也不让语言模型临时猜一个价格。改漆色或加花纹不增加结构成本；扩面积、加楼层或门廊应产生相应材料增量。同一模板版本的费用应可重复计算，并向玩家展示为什么变化。具体系数与首批建筑样式尚未确定，不把示例数值写进正式经济。

工地保存所选模板版本与当时的材料清单。后续编辑模板不自动改变在建或已建房屋，避免少交材料、重复退款或外观突然变化。改造已有房屋应单独预览变更、材料差额和已有投入处理方式。

## 野外烧烤：建议的最小活动

先验证一处可用的野外活动位置，支持你和一位AI共同参与。地点应可达、不会堵住道路，遵守地图区域用途；不默认任意资源地都能摆设备。

1. 共同设计或选择烧烤设施作品，预览摆放与材料需求。
2. 商量吃什么、谁拿食材、谁准备燃料或餐具；必要选择在游戏内问答。
3. 实际从箱子取物，搬到现场，准备、生火、放食物、翻面、取出。
4. 一起坐下吃东西和聊天，最后熄火、收拾，剩余食材仍是实际物品。

设施通过像素模块制作外观及冷态、燃烧、烤制、熄火等状态；人物通过同一角色作品系统制作生火、翻面、递食物、坐下吃东西等动作。手、工具、食物、座位和火源使用独立对齐点；不能只把走路帧上下抖动后宣称完整烧烤动作。

动画帧、配方和物品流分开：图片画出食物不代表真的产生食物，火焰动画也不自行扣燃料。食材来源、燃料、配方、熟度时长、多人分工与收益仍需细化。为验证烧烤，先补最少一种正常可获得的食材，不给玩家存档凭空塞食物，也不先扩成完整烹饪系统。

保持无体力、无强制睡眠。烧烤的价值主要是互动、分工、共享时光与可见记忆，而非强制每天吃饭才能工作。火候和动作由游戏推进，聊天、选择与必要事件才调用模型；不因坐着等待持续推理。

## 第一轮验收目标

- 围栏连接自然，田地作为连续区域融入地面，同时仍可准确点击每块菜畦。
- 玩家与AI通过同一工坊编辑房屋模板；两种真实结构不同的房屋有可解释的不同费用，纯换色不改费用。
- 从模板开工后，修改原模板不会悄悄改掉旧工地；取料、施工、取消和重启守恒。
- 烧烤设施可编辑，至少一套设施状态和角色操作动作可在实机连续播放，脚底/手持物不漂移。
- 双方能完成一次取料、准备、烤制、一起吃、收拾的活动，任务和对话反馈来自真实状态。

优先顺序：修围栏/田地 → 工坊公共作品层 → 房屋模板与材料计算 → 烧烤设施/动作及共同活动。暂不优先扩大海域或增加多模型数量。

## 2026-10-23 实施更新（0.3）

已完成首版：连续田地与畦间路、连接围栏与可通过门口；通用作品校验（人物/建筑/设施）、公共画布与图层编辑、建筑结构与费用预览、模板编译和工地版本锁定；烧烤状态与生火/翻面/坐下吃动作由同一工坊作品生成。

建筑初值公式：地板=ceil(宽×深×层/4)，框架=ceil(2×(宽+深)×层/3)，墙面=框架+4，屋顶=ceil(宽×深/4)，收尾=8，门廊=宽×门廊深度。五阶段汇总地板/框架/墙面/屋顶/收尾+门廊；8×7单层无门廊为60木材，10×8双层一格门廊为130木材。颜色和像素数不参与收费。旧版已开工建筑继续原64木材费用。具体长期平衡仍待试玩。

烧烤首版在公共草地有一个可编辑的石圈烤架；暂不收费建造这处公共设施。采蘑菇→存箱→搬2木材/2蘑菇→生火→等待翻面→翻面→两份食物→两人用餐→收拾。每丛4蘑菇，采后6小时再生；只有本轮加入的三丛野外点提供食材。每面12秒，操作翻面3秒，用餐9秒；计时由引擎推进，不用模型逐帧推理。未引入饥饿或体力。

开烤时锁设施作品，结束收拾后下一轮才用新版。世界进度升级schema3，仍用island-v2.json文件路径以延续玩家数据；schema2加载时补默认新功能，原房屋、人物、库存与携带物保留。活动中断不丢已搬到现场的物资，用餐记忆保存；不自动唤醒AI接着做下一阶段。

玩家和AI可编辑共享作品；AI按24×24像素区块读取、按版本提交像素或结构修改。工坊可清空图层自由重画，当前提供两个建筑起点与一个烧烤设施；任意新作品命名/无限目录、复杂自定义碰撞和室内创作尚未提供。
