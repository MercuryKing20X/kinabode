## 外部MCP连接

1. 在对话里为目标居民选择模型控制。
2. 底部“动作→功能动作→AI接入配置”选择居民，点“接入外部AI并复制配置”。主机明确切换该居民连接，取消旧代回复并停止本人工作；真实物资、旧原生线程记录与身份保留。
3. 将复制的mcpServers配置粘入支持本地stdio MCP的客户端。配置固定世界ID、居民ID、数据目录，脚本为scripts/habitat_godot.py；若Python环境不同，可调整command或设置HABITAT_PYTHON。不包含凭据，不修改全局设置。
4. 客户端用observe/game_actions检查真实身份与能力。游戏中给伙伴发消息后，dialogue_poll读取待处理请求；客户端实际运行自己的模型，再返回真实事件。邮箱可用不证明提供方已推理。
5. “返回原连接”恢复保留的原生/主机适配器。绑定本身不启动模型，不接管桌面开发会话。

这是一键绑定和生成连接配置；不自动安装第三方客户端、登录提供方或唤醒未运行的外部程序。客户端须主动读取邮箱、调用自己的模型并处理游戏取消；游戏停止会拒绝旧回复，但不能声称已停止外部提供方的计算。

## 动作契约version2

MCP game_actions无参数，返回当前绑定居民、世界、动作分类、参数和可用条件。game_action结构：

```json
{"action":"fish","arguments":{}}
```

动作：fish无参数；move要求x/y、可选region_id；stock_fish要求fish_id/pen_id；release_fish要求fish_id；stop无参数；gesture要求wave或stretch。不允许actor_id或额外字段，坐标必须有限；引擎最终校验能力、当前海岸、手持、占用和任务，不能靠UI available绕过。

外部邮箱模式下必须附当前dialogue_poll.pending的准确六字段，不能使用无上下文act绕过取消：

```json
{"action":"fish","arguments":{},"dialogue":{"world_id":"本次世界","resident_id":"绑定居民","scope":"direct","session":"当前会话","generation":0,"request_id":"当前请求"}}
```

scope的实际值必须原样复制，不能照抄示例。game_action把动作路由到准确邮箱回合并返回引擎实际结果。接单不等于完成；后续观察真实job/pending，超时先观察，不能盲重试写入。工具不会为等待自动启动新模型回合。

## 外部消息协议

dialogue_poll可选scope=direct或group，读取独立频道邮箱。pending包含world_id、resident_id、scope、session、generation、request_id、text和world快照。无待处理请求就不应伪造回复。

dialogue_reply要求上述六字段、唯一event_id、event。event.kind支持assistant(text)、question(text,choices可选)、action(command)、complete。action回执在result及邮箱results中；同一事件ID重复拒绝，每回合最多64事件、保留32工具回执。提问必须经游戏里准确回答才能继续动作或complete，不把等待当许可。

单聊/群聊独立scope与连接，同一居民同时只在一个scope推理。取消、换源、重载使旧身份失效。外部API不能切controller、发起主机集合/邀请或替人类走路。助手回复不会自动唤醒其他伙伴。

## 原生旧模型会话兼容

此接入最初基于VERSION0.3.0；当前原生驱动已因玩家显式开启的预算自主回合升为0.4.0，原DYNAMIC_TOOLS/schema与原thread ID保留，兼容恢复0.3.0记录，详见[预算自主行为](AUTONOMY.md)。thread/start和同一thread/resume附加当前线程专用youqi_actions MCP配置，通过model_actions_mcp.py提供game_actions/game_action；不是修改全局MCP，也不在旧枚举里静默增删动作。

每次真实游戏消息注入action_turn_token，模型调用须带该回合令牌。专用helper邮箱验证令牌/时限/去重，经原FileTransport与准确actor/scope/generation屏障执行；取消或完成令牌失效，空闲调用不唤醒模型。会话恢复失败保留旧记录并报告错误，不另建替代线程。不会将外部read-api凭据交给模型绕过既有取消流程。
