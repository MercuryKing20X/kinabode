# home-v3 时段与环境表现

2026-10-31声音层更新：原moon_tide等十个WAV保留来源与legacy回归，但Main成功加载新声音清单后关闭旧播放器，统一由GameAudio观察真实昼夜、天气、镜头海岸和双营火。新海浪/风/鸟虫/雨/噼啪/滋滋、四材质脚步、六首循环与混音说明见docs/AUDIO.md；环境音均为可重复程序合成，不声称自然录音。视觉层原参数不变。

本层只绘画面，不创建任务、不调用模型、不产生记忆，不改人物作品、HUD结构、玩法随机、物资或存档。配置为 `godot/content/ambience.json`，实现为 `island_ambience.gd` 与独立暖光子层 `island_ambience_lights.gd`，由 `island_v3_view.gd` 接入；旧 core 视图不变。

## 时段与光

唯一日历仍是 ForestSystem.clock → DayCycle。直接读取 within_day / day_seconds 与现有四时段起点，没有第二套日历。每段最后60秒以 smoothstep 平滑过渡到下一段，包含夜晚到次日清晨；重载直接重算当前颜色，不补历史。

|时段|场景乘色|暖光强度|薄雾透明度|
|---|---|---:|---:|
|清晨|#FFF0D8|0|0.025|
|午后|#FFFFFF|0|0|
|傍晚|#F4BA8A|0.45|0|
|夜晚|#657CAA|1|0|

场景使用 self_modulate，人物保持可辨认；HUD在独立CanvasLayer，不被乘色。暖光是子CanvasItem绘制，避开父self_modulate与天气罩：路灯玻璃/地面光、实际建成屋子的窗格、凉亭/舞台灯串。窗光仅来自开窗元数据中的原母版玻璃像素，镜像屋同步镜像遮罩；保留窗框，不点亮整片蓝屋顶。遮罩按真实冻结作品ID/修订与工地缓存，不修改作品。陌生自定义作品没有开窗元数据时不猜窗。灯玻璃按原灯素材四块玻璃区域描光，不在灯杆上画漂浮光块。

营火沿用 EnvironmentMotion.heat 的真实状态：cold 无光，cooking/needs_turn、ready/eating、embers按现有燃烧/余温强度绘制。不开假火，不为了氛围消耗或生成材料。室内继续原有渲染。

## 环境动态与上限

- 已建房屋按其已知母版/零件中的烟囱锚点冒烟；每烟囱最多3烟团，全屏最多24。只有真实stage_index≥5、带冻结作品的房屋才参与，未建宅地不冒烟。
- 海岸64条、码头最多16条浪花候选，启动时从真实海岸与栈道几何缓存；当前72条。只画当前视口附近的短白浪，不创建水域/碰撞。
- 白天鸟6、蝴蝶10；夜间萤火虫20。过渡时两组可重叠，生物总上限36，不增生。小雨降低白天可见度，数量上限不变。
- 旗子、灯串、风铃、花叶复用 EnvironmentMotion.wind；小道具按整像素偏移，原树叶仍走既有风动。凉亭/舞台各7灯珠；没有新美术体系。
- 使用专属 RandomNumberGenerator，固定表现种子3102703；只在准备时生成相位/位置，不调用全局随机或钓鱼/天气/作物随机。view.clock只驱动烟、浪、翅膀与风，不驱动游戏时段。

现有多云、小雨、雾叠在场景内，暖窗与灯光在天气罩之后绘制；雨不浇水，不改鱼概率/作物/移速。海岸与窗口遮罩缓存不逐帧重建，屋况每2秒只读刷新；离开使用的窗口缓存释放。新表现没有存档字段。

### 缓存边界

- 静态地面/道路/码头烘焙一张5120×4096透明GPU纹理；原连续多边形和原素材只绘一次。相机、昼夜、人物移动不重建。
- 农田地面单独约2125×378纹理；只有布局/湿土等真实视觉状态变化才重建，作物、工作效果与名称仍动态。
- 总览静态道具另烘焙一张5120×4096透明纹理；普通视角保留原逐物件Y排序，总览保留人物附近前景重绘。树木、人物、作物、设施/棋盘、火、风动物件、鱼、粒子和灯光不烘成静物。居民改名/相关工坊作品修订会刷新道具缓存。
- 显式布局绘制失效会重建，实际GPU探针验证：跨日夜/相机/帧推进静态地面仍只烘1次；修改绘制副本后显式失效增至2次，World.revision不变。缓存不持久化，不进快照，不拥有路线。
- 颜色纹理约163MiB（不含驱动帧缓冲/原素材），以显存换CPU；headless测试使用原绘制回退。没有改生产tick。

## 月牙岛表现与缓存（2026-10-28）

连续多边形+原草/沙纹理与不规则边缘照旧；月牙岛另烘6080×4096西侧透明地面缓存，主岛5120×4096地面和总览道具缓存保持，避免11200px整张缓存。颜色缓存总量约258MiB（不含驱动附加缓冲），寻路为同一44800格World网格。

月相为8天循环：第1天新月、2眉月、3上弦、4盈凸、5满月、6亏凸、7下弦、8残月，再循环；读DayCycle.day，不使用玩法RNG。亮度(1-cos(phase*TAU/8))/2，满月最亮；夜晚绘制像素月盘倒影与横向波光，雨/雾隐藏，不假造晴夜。暖灯复用原灯素材/子光层；两个烧烤炉各只随自己的真实火态发光与响声。

海岸波纹预算仍64+最多16码头候选，其中24分配月牙岛；鸟6/蝶10/萤火20总上限不变，原专属RNG分配少量到月湾。使用原素材风动；烟囱仍只来自原真实建成房屋，月牙岛不造住宅。潮声为独立离线原创滤波噪声12秒循环moon_tide.wav，仅月牙岛镜头区域播放，不读/改玩法随机与tick；素材来源见 [CREDITS.md](../CREDITS.md)。新岛树/礁石/箱堆都是原素材纯景物，不伪造可采物资。送花小径锚点复用道路数据，排除实际栈道面，木平台不长草。
