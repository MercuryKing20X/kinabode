## 使用入口

- 底部「对话」旁新增「集合」。所有非玩家居民暂停当前工作，走到玩家附近的独立站位，朝向玩家；全员到达后保持60秒。按钮变为「解散」。只做呼吸、眨眼，不自由散步。
- 上方「游玩」选择双人秋千、茶歇凉亭或林间舞台。可以选择建造者、参与者，也可以从已保存模板摆放新的设施地基。
- 进屋、落座、吃烧烤、跳舞、游玩共用参与者选择。玩家也可以参加；所有居民都可执行本地社交活动。施工和农场管理仍要求工作能力。
- 「像素工坊 → 人物」中选居民改名，或者把已保存的人物作品绑定给她。居民名字与作品名字分开；改名不会改变ID、农场归属、物品、任务或模型会话。
- 工坊支持新建空白、复制、导入和导出JSON作品。建筑图纸、游玩模板列表从作品库动态读取，新增作品不需要再修改固定ID列表。

## 设施模板

设施作品 `kind=facility, facility_type=recreation` 有 `idle` / `active` 像素帧和 `recreation` 配置：

- `width/depth`：占地格数，宽3–12，深3–10。
- `entry`：入口相对中心坐标。
- `slots`：1–8个独立交互点，至少相距1.2格。
- `obstacles`：相对中心的障碍矩形 `[x,y,width,height]`。禁止遮挡入口、座位及形成封闭座位。
- `behavior`：`swing`、`sit`、`dance`；`seconds`：5–300秒。
- 可选 `rigs`：秋千绳与座板的像素区域、旋转轴和座板连接点，用于实际摆动。工坊几何编辑保留这些字段。

木材需求由规则计算：`ceil(width*depth/3) + slots*2 + 行为附加量`，秋千8、围坐12、跳舞4。默认秋千26、凉亭36、舞台28根木材。不能通过像素画面或随便填一个价格绕过实际投入。

摆放验证陆地、农田、树木、房屋、箱子、其他设施和居民。首次放置/开工锁定模板版本；之后编辑用于下一座设施，已投入的实例不会悄悄改变成本或碰撞。所有施工都取实际木材，最多携带6根，走到地基交料，足额后施工。材料不足保留已交数量。取消、集合、重开也保留箱子、手持、地面物品和设施投入。新设施先是地基，没有免费成品。

占座由 `site_id.slot.index` 独占预约，去座位的路上也占位；满员明确失败。停止、集合、路径失败或活动结束释放预约。运行时摆动仅改变绘制位置，不改变逻辑坐标或增加第二套移动。

## 读取与扩展

`observe` 返回 `leisure.sites`（配置、材料、占位、完工情况）和 `gathering`（到达、等待、失败）。像素数组仍不进入世界快照。新增动作：

- `build_facility(target_id)`：搬运已有木材并施工；材料不足结束为blocked，不暗中持续推理。
- `use_facility(target_id)`：预约、寻路、活动、释放位置。
- `greet / come_near / dance / watch`：本地社交动作。

`read_work/edit_work` 接受作品库中的共享建筑、设施和植物，按版本校验，支持完整 `recreation` 配置补丁；仍不能改另一位居民的外形。扩展新视觉、尺寸、交互点和三种已有玩法只需数据；全新玩法种类仍需实现并验证对应行为，当前不执行作品携带的任意脚本。

存档schema7向前兼容schema2–6；名称进行一次迁移，此后尊重改名。正在进行的集合、游玩及施工工作不在重启后自动执行。新增测试覆盖四人集合、完整60秒、真实物资施工/取消/重开、双人占座与满员、独立改名、导入导出、新居民资料、新设施放置、非法几何和控制器取消/邀请。默认模型验证为fake，没有实际模型费用。
