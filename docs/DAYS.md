# M3 · 天计数与每日小事


## 唯一日历时间来源

复用 **ForestSystem.clock / forest_clock**。没有新增会累加delta的日历时钟，没有把农田、鱼资源或做菜计时改造成日历时钟；这些系统保留原计时语义。

DayCycle只保存起点和每日标记。默认25分钟（1500秒）为一天：

`day = 1 + floor((forest_clock - origin) / day_seconds)`

实际投影统一到整数毫秒后再相减/取整，避免Unix大浮点时间经JSON往返后，在第1500秒边界前后跳一天。起点创建时落在当前森林时钟的毫秒内，旧档也从当前时刻的第1天开始；不修改森林时钟本身。day_seconds随新可选状态保存，冻结本世界的周期，配置范围1200～1800秒。

`World.advance`保持原资源/任务推进规则，在森林及其他既有系统推进完成后调用 `days.advance()`。该方法**没有delta参数**，只读森林时钟。真实钓获先排入有界当帧事实队列，在此统一结点归日，因此跨天瞬间的钓获、每日标记和HUD采用一致日界。HUD/附加图鉴提示每显示帧读取结果，不另行计时或累加天数。

离线恢复仍使用既有森林/农田/钓鱼恢复逻辑。日历可直接来到当前日，不逐日调用活动、不补过去的台词或小事。跨天只换当日去重桶：库存、携带、建造、任务、原永久图鉴不重置。没有体力、睡眠、日历锁、建造解锁或额外收获；农田离线仍只到一个成熟批次，不自动收获/补种。

## 三项作用

### 1. 伙伴作息台词

数据在 `godot/content/day-cycle.json`。默认清晨0～28%、午后28～58%、傍晚58～80%、夜晚80～100%。各阶段全村最多接受一次作息短句，且要等该阶段至少30秒，再等真实的空闲发言机会。夜晚只换措辞，不让人睡觉或停止劳动。

复用ResidentDirector的local_rules发言出口，遵守个人/村庄发言间隔、日常活动与碎碎念开关、对话/问题优先、近玩家范围、停止安静期。忙于真实任务/路线/计划、集合、烧烤、下棋或手持物资/鱼时不参与。时段台词不阻止原有递花等日常动作的正常选择；错过某阶段不补播。

统一本地出口现在也附带现有发言事件的time字段，使作息与原日常声部具有同一村庄时间轴的限频证据；未改模型对话或旧驱动。

### 2. 每日一次本地小事

**全村每个游戏日最多启动一次**，不是每位伙伴各一次。默认在当天180秒以后，挑选当前可参与的非人类居民，原地招手或伸懒腰并说一句明确标为“日常”的短句。内容从配置选择，参与者来自实际居民目录，不固定名字、人数、控制器或模型提供方。

动作调用现有World/Work的gesture，沿用既有手部/身体表现。没有新物资或路由；不移动人类、不代人类发言。仅已空闲且允许日常活动的居民参与，不抢正在进行的任务、聊天、计划或路线。日常小事可以占用一次空闲选择机会，最终执行仍在统一日历结点接受；不会用一串补播填满离线天数。

每个动作有准确owned_job_id，标为source=local_rules并挂在该居民原LocalCompanion下。停下、提问、切源、关闭日常活动和对话hold只中断其确切归属任务，不能取消后续替换的人工工作。接受时状态started，真实gesture完成才completed，中断为interrupted。**当天启动过即用掉机会**，取消或同日重载不重演。重载started变interrupted，不恢复工作、路径或占用。

### 3. 图鉴“今日首次”

针对每位居民、每个鱼种/颜色/体型组合，记录本游戏日第一次实际钓获。捕获同一已知组合，第二天也可以有新的“今日首次”，但不会改写M2永久的第一次钓获。

数据单独放在DayCycle的first_today桶，保留真实fish_id、维度、体型、海域与实际钓获时间。只接受真正提交的鱼，取消、等待、旁人钓获或读取均不计数；放生、入场和做菜不抹去已发生的当天事实。跨天清理当天提示，永久记录不动。

`day_journal_overlay.gd` 是展示附加层：在现有发现册头部显示“第N天 · 今日首次N种”，在实际组合卡上显示“今”。**journal_system / journal_panel / journal_card均未改动**，M2的永久保存内容、首次时间、128格和独立分页修订保持原样。本轮不加新图鉴查询动作；observe.day只提供本人的当天数量及日历摘要。

## HUD与存档

左下角原操作提示上方显示“第N天 · 时段”，普通Label，忽略鼠标输入。顶栏按钮数量和stock标签不变，也不占用底部居中的对话/动作/集合按钮。

schema仍7，增加可选 `day_cycle`：

| 字段 | 内容 |
|---|---|
| version | 1 |
| origin | 日历起点，森林时钟秒值，毫秒精度 |
| day_seconds | 本世界冻结的一天长度 |
| marked_day | 当前去重桶归属的日号；天数本身始终从森林时钟投影 |
| spoken | 当天已接受作息短句的阶段ID |
| small | 当天小事ID、实际居民、配置事件ID和started/completed/interrupted；未启动为空 |
| first_today | 居民→组合→该日首次真实钓获事实；每人最多当前图鉴组合数 |

不存无限日流水、不保存动态任务ID、不回填不存在的旧历史。旧档无字段时在恢复森林时钟之后建立新起点，空标记、第1天。当前日重载保留已用机会与当天钓获；离线越日只留下新当前日的空桶，不触发任何活动。验证起点/周期/日桶/居民/阶段/唯一鱼ID与体型来源，非法字段保留原档副本并拒绝加载。

`test_days_controller.gd`验收实际左下HUD、顶栏数量不变、输入不拦截、1280×800和960×640的当天标记、跨天仅去掉“今”而保留彩色卡、真实小事动画/日常气泡及真实绑定问题中断。假适配器、无真实模型调用。旧森林迁移夹具在去除forest_clock时一并去除后来新增的day_cycle，符合真正旧档结构；森林原规则不变。
