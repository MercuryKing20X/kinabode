# 松散日程与表现天气

ScheduleSystem 不创建第二套居民调度器：只在既有 LocalCompanion._choose 空闲选事时提供偏好，用原_move_to→World.command路由。日常120秒后，40%机会尝试，开始后150秒再尝试，失败20秒；到场停留16秒，原路线24秒保护不变。真实工作、携带、held/问题、集合、开关、停止120秒与现有行为优先，不自动恢复工作，不控制human。所有参数与地点类别在content/schedules.json。

清晨偏海岸、午后偏菜园、傍晚偏营地、夜间偏实际已完工屋前或真实已建可坐设施。目标来自现有海岸探测/农田几何/营地/完成房屋门口/已建设施，通过World.walkable与共享目的地检查；无可达遮雨处就保留其他空闲选择，绝不假称进了不存在的屋。不是赶时间任务、不是睡眠或日历锁。日程只有内存偏好，重载清空路线/目标，不补离线行程。

WeatherSystem只从既有DayCycle.day派生（ForestSystem.clock是唯一日历），每岛独立随机种子+天数决定当天天气。content/weather.json晴35/多云30/小雨25/雾10；仅权重，不是现实气象。独立RandomNumberGenerator，不影响钓鱼、作物或世界随机序列。schema7可选weather={version,seed}；旧档从当前起表现天气，无历史、无奖励。种子覆盖String.hash的完整无符号32位范围（0～4294967295），在相同内容配置下保证重载/跨天一致。

天气只改画面色罩、像素雨线/薄雾，以及空闲地点偏好/真实雨雾日程短句；不改情绪系统数值、不改变生长/自动浇水/产量/鱼概率/速度/容量。小雨偏实际门廊/凉亭，雾偏营地近处；日程发言仍走原共享出口，疲惫/高兴/安静原句池不覆盖。现有左下天数追加天气，无新按钮。画面天气只在岛外景、人物与气泡之间绘制，不覆盖UI或室内。

美术来源：所有人物/场景继续用已有原创像素与作品；新增weather_renderer只有细小1像素斜雨线、透明色罩/雾带，不新增素材、不调用图像或模型、不替换原画体系。


## 月牙岛夜间偏好（2026-10-28，用户明确授权路线例外）

普通日程24秒路线保护保持。只有月牙岛赏月目标按真实路线长度/正常速度+8秒余量计算，最多90秒；属于同一World路线，没有传送、分身或第二套时钟。夜晚每3个游戏日，按稳定居民ID轮换，仅1名伙伴获得权重0.15的可选目标；不是保证执行、不是全村夜游。到场复用原Leisure座位任务，source=local_rules并持有精确owned_job_id；真实任务/对话/held/停止等仍优先。

月牙岛共用home的实际天气。晴/多云可见月湾月光，小雨/雾无月亮倒影；不影响任何作物、鱼概率、物资或速度。7项专项真实advance验证远程路线越过24秒仍真实到达、原座位任务、停止安静与人类不动。
