# 结伴交料 · 无人值守阶段5

CooperationSystem只读取已有World任务和站位，给当前“放下交付”的handle_bundle计时一个倍率，不创建路线、工作、认领或投入，也不调用模型。配置content/cooperation.json：enabled、delivery_factor2、extra_site_range3及现有交付phase/intent列表。

适用：建房build_delivery/deliver_wood，或家园homestead.step=deliver。另一位居民须有同一目标的有效交付/施工任务、同区域、没有在途路线、已在工程点范围内；路过、农庄/存箱/做菜/设施任务都不算。只缩短这一次交付手部动作，不改取料、不改全局移速/载速、CARRY_LIMIT20、树产/箱容量、BUILD_SECONDS3或家园6秒施工。

倍率实时重算，不存第二条动画路线。任一人停止/离场/任务结束，下一次计时立即用单人倍率；已积累的交付动作进度继续，真正交料仍只在原Work/Homestead扣carry并记入目标的同一提交点。没有提前扣料、复制、合并背包或新增存档字段。取消/重载原规则保留物资，不恢复旧任务。

原居民工作状态增加“结伴交料”，observe.self.cooperative_delivery仅给布尔摘要，无像素或额外计时。沿原姿态/载重叠图，不新增美术。

专项26项真实时间与资源测试：先实际砍树，各人持8木，真实走到同一工地，再接受builder/helper；关闭合作对照0.450/0.450秒，合作0.250/0.250秒（25ms帧，理想0.225秒有一帧舍入）。途中停止一人后另一人按单人计时继续，总木材16不变；取消/重载仍16，无恢复任务。真实家园收据也完成16/24交料并保留剩余8；不相关任务倍率1。


边界：这是交付手部动作的协助，不是新增两人共同托举的专属角色动画或共享物件物理；整趟走路时间不减半。只在双方真实任务/站位都符合时生效。
