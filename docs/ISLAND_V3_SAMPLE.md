# 主岛v3第1段：独立美术样板


**当前主岛不替换，存档不迁移/不重置。** home-v3未注册。样板id为island-v3-sample，40×25格、32px格，住宅街半层16px，三座已有模板房屋，四位原人物仅作比例参照。它没有World、Work、模型连接、时钟、输入控制、存档或人物发布路径，不是可游玩世界。

入口godot/scenes/island_v3_sample.tscn；语义布局content/island-v3-sample.json；规范content/island-v3-style.json。房屋直接用CharacterLibrary解码cottage/cottage-blue/cottage-large的stage_4，人物直接用当前随项目可编辑原作的方向帧；不改作品、姓名、性格、控制方式。不读取玩家存档。后续游戏中复用玩家自定义作品还要由正式World/Library绑定接入，本轮不提前迁移玩家身份。

新增井、告示板、路灯、花盆、长椅、木箱堆、草花、邮箱、望远镜、书架、风铃、营火与门牌为原创脚本像素；房屋与人物只读复用JSON，树木/石头复用既有原创PNG（无新生图）。阴影统一左上光/右下影/底部接触影，夜晚蓝环境与窗口/灯/火暖光；窗口亮部派生遮罩只在内存里生成，不修改原作。

所有像素以原尺寸整数倍显示，关闭场景窗口的canvas_items非整数拉伸；960×640居中裁景，三房四人完整保留，边缘树木作为允许出血。detail用实际2倍镜头，绝非PNG放大。静态地形缓存只有一次构建，换昼夜/尺寸不重建，逻辑与渲染不分享随机源。
