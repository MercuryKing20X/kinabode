# 海风棋角与本地下棋能力 · 0.10.9

2026-10-26。首批闭环是玩家邀请一位任意有社交能力的居民，真实入座，下完一局，并留下真实对局记录。只使用Godot，不导出应用、不接入新模型服务。

## 在哪里、怎么玩

默认棋角在初晴岛(45,76)，凉亭旁。顶部“下棋”、点击棋桌，或“游玩”中选棋桌后打开。首次只有地基，需要26根真实木材；选择建造者复用现有取材/搬运/施工，材料不足保留已有投入。没有免费成品，座位与人物移动仍由World/Work负责。

如果旧世界这块地已被树木、房屋、农田或设施占用，建造会拒绝并保留进度；可以通过“游玩→海风棋桌模板→摆放新设施地基”选择另一块合法地面。模板可复制和编辑，多张棋桌各自保存棋盘与对局ID，玩家同一时间只能参加一桌。

建好后选伙伴、执黑/执白、本地/模型模式及轻松/认真，点“自己入座·开局”。这是玩家明确参加并走向棋位的动作；仅打开面板/看棋不移动人。忙碌、手持、农庄/建屋计划、集合/烧烤或待回答问题需要先处理，不抢任务。两人都真实到场后开始；新建/开工棋桌冻结其原作品与几何，后续改模板不覆盖旧实例。

首版15×15，无禁手，黑先，双方交替在空交叉点落子；横竖斜连续五颗或更多获胜，满225颗仍无连五则和棋。棋盘标记最后一手和实际胜线，状态显示双方执子、当前轮次和结果。落子由引擎校验，不允许重复点、越界、抢回合、代别人下或终局后继续落。

## 本地棋力与模型模式

本地棋力是内嵌规则程序，不需要模型连接，不调用/冒充模型推理。两档都优先直接连五或堵住对方连五；其余根据连续子、开放端点和攻防分数选择，轻松在前三候选中变化，认真增加有限应手评估。等待0.9～1.8秒才落子，不是立即秒下。主搜索预算12毫秒，最多8个根候选/16个应手评分；15路棋盘和初始威胁扫描也有固定上限，但这不是专业棋力或严格实时总耗时保证。

“模型落子”要求该居民确实使用模型控制。本地棋力不会暗中代下，不自动发起新模型回合。对方回合可明确点“请模型走这一步”，通过当前游戏连接发送一条真实玩家消息；一回合只要求当前一步，之后等玩家。未连接的外部客户端仍需自己读取邮箱和真正运行模型；不能把等待说成已经思考或已经落子。正常聊天可与下棋共存，需要明确选择的问题会暂停整局，回答后仍需明确继续。

本地开局/落子/结果短句标“日常”，共用原ResidentDirector发言限频、个人日常/对白开关及真实对话优先级，不替人类说话、不进行自动无限互聊。原人物作品保留，当前为空手近似坐姿和手部落子叠层、轻微看棋动作，尚非一套完整新绘人物棋姿。

## 收起、离座、暂停和恢复

收起大棋盘仍坐在桌边，底部保留回到当前对局的入口，桌面显示实际棋子；顶部“下棋”优先打开自己的活跃桌。只看另一桌不会改变它的棋谱。

“暂停离座”、停止任意一位、集合、换控制来源或真实提问会暂停对局，释放准确归属的任务和座位，棋谱保留；不能在未暂停时另接工具工作。继续按钮明确让玩家和伙伴重新走到原位，不恢复旧劳动。其他人在用座位或棋手忙碌时继续失败，不抢占他们。等待到场最多120秒，超时暂停。

重启保留棋盘/执子/结果，所有未结束局恢复为暂停，修订号增加，任务/路线/占座/本地思考倒计时均不恢复，不在离线时落子。旧模型请求即使持旧棋盘也不能继续执行。认输需玩家明确确认，记录为认输；单纯暂停不算输。

## 保存、真实共同记忆

schema7新增可选gomoku子对象version1，保存按桌索引的对局及最近32个终局来源。棋盘由真实history重放生成，逐手验证坐标、空位、轮次、终局与结果；JSON整数/浮点坐标按数值等价恢复为整数。非法历史、假胜者或终局后的额外手进入已有.invalid副本保护。

旧档无gomoku时无对局、无历史；仅为缺失的新默认棋角加空地基，不补木材、重置旧设施或覆盖角色作品。读取/暂停/重试/接受邀请不生成完成记忆。

真实连五、和棋或明确认输才提交gomoku_match，SharedMemories导入实际双方、黑白身份、棋桌、步数、结果与胜者，完整历史留在来源记录中。暂停局没有胜负记忆；认输不会被文案说成连五。source_marks容量随第六组32条来源扩至192，统一日记仍256；回忆面板和read_memories可按gomoku_match读取，非参赛者不会被记为下过这局。
